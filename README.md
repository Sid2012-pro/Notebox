<<h1>NOTEBOX</h1>
A tiny chiptune-style music maker that runs entirely on your browser.

<h2>What is Notebox?</h2>
Note box is a mini retro styled Digital Audio Workstation (DAW) for making short loops.
It features:
<br>
<li>
  <item>3 synth tracks and 1 drum track</item>
  <item>A piano roll</item>
  <item>A 8 row beat sequencer</item>
  <item>Instrument controls</item>
  <item>A track Mixer</item>
  <item>and more....</item>
</li>
<h2>How to run it locally?</h2>
Simply download the 3 files - script.js, style.css and index.html, put them in the same folder and open index.html to run the project 100% locally.

<h2>How does it work</h2>

The DAW uses  Web Audio API for audio , HTML canvas 2d for  the piano roll and sequencer. and vanilla HTML 5 as the tech stack.
